=========================================
  SURGEON SIMULATOR 2 - PRIVATE SERVER BY ARI
=========================================

Hi! This lets us play Surgeon Simulator 2 co-op again on Ari's server.


INSTALL (only once)
-------------------
1. Keep this "Server Installer" folder INSIDE the game folder
   (the folder that has "Surgeon Simulator 2.exe" in it).

2. Open "Server Installer" and double-click  SS2Revival-Installer.exe

   - If Windows says "Windows protected your PC":
     click "More info" -> "Run anyway".

3. It asks "Who are you?" and shows your Steam accounts.
   Type the number of your account and press Enter.
   (Or pick the last option and type any name you like.)

4. When it says "Done!" in green, press Enter to close it.

That's it, you never have to run the installer again.


PLAY
----
1. Start "Surgeon Simulator 2.exe" in the game folder.
   Steam does NOT need to be open.

2. You'll see "PRIVATE SERVER BY ARI" at the top of the screen.
   Wait for the funny loading messages, then press Play.

3. To play together:
   - Ari invites you from the party menu in the lobby, OR
   - press Shift+Tab to open the PupBerg overlay and join Ari from there.


GOOD TO KNOW
------------
- Voice chat in the game doesn't work anymore, use Discord.
- Your XP and daily challenges are saved on the server.
- Don't move the files out of "Server Installer", they belong together.


SOMETHING'S WRONG?
------------------
- Stuck on "Loading [100%]"  -> the server can't be reached. Check your internet,
  then tell Ari.
- Installer says "this is not the 1.5.1.561 Assembly-CSharp.dll"
  -> wrong game version, ask Ari.
- Want to undo everything? Open a terminal in "Server Installer" and run:
      SS2Revival-Installer.exe uninstall

Have fun and try not to lose the patient (or your arm) <3
